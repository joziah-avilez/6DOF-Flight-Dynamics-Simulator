# 6-DOF Flight Dynamics Simulator

A C++ six-degree-of-freedom rigid-body flight dynamics simulator for exploring numerical simulation, vehicle dynamics, aerodynamics, and attitude motion.

The simulator integrates the coupled translational and rotational equations of motion using a fourth-order Runge-Kutta (RK4) method. Vehicle attitude is represented with quaternions, aerodynamic forces and moments are evaluated in the body frame, and the resulting state history can be visualized in Python as a 3D trajectory or animated flight.

## Current Features

- Coupled 3D translational and rotational rigid-body dynamics
- Quaternion-based body-to-world vehicle orientation
- Body-frame angular velocity
- Full inertia tensor representation
- Gravity and body-frame thrust
- Wind-relative aerodynamic velocity
- Separate axial and lateral aerodynamic drag
- Aerodynamic restoring moment from center-of-pressure offset
- Airspeed-dependent pitch, yaw, and roll damping
- Applied body-frame torque
- Torque-free rotational coupling
- Fourth-order Runge-Kutta (RK4) time integration
- Quaternion normalization during integration
- CSV state-history logging
- Python 3D trajectory visualization
- Quaternion-driven 3D flight animation
- CMake build system
- Eigen-based vector, matrix, and quaternion operations

## Numerical and Physical Validation

The implementation has been tested using analytical solutions and physical consistency checks, including:

- Constant-gravity motion compared with the analytical solution
- RK4 constant-acceleration trajectory
- Quaternion rotation compared with analytical angular motion
- Constant-torque angular acceleration compared with the analytical solution
- Conservation of rotational kinetic energy during torque-free motion
- Conservation of angular momentum magnitude during torque-free motion
- Axial and lateral aerodynamic force-direction checks
- Vehicle-orientation and wind-relative aerodynamic tests
- Center-of-pressure restoring-moment test
- Pitch/yaw aerodynamic damping test
- Isolated roll-damping test

## Build

Clone the repository and configure an out-of-source CMake build:

```bash
git clone https://github.com/joziah-avilez/6DOF-Flight-Dynamics-Simulator.git
cd 6DOF-Flight-Dynamics-Simulator
cmake -S . -B build
cmake --build build
```

CMake locates Eigen and configures the required include paths automatically.

## Run the Simulation

From the project root:

```bash
./build/flight_sim
```

The simulator writes the state history to:

```text
output/simulation.csv
```

The CSV contains time, world-frame position and velocity, quaternion orientation, and body-frame angular velocity.

## Visualization

After running the simulator, display the static 3D trajectory with:

```bash
python3 visualization/plot_trajectory.py
```

Run the quaternion-driven 3D flight animation with:

```bash
python3 visualization/animate_flight.py
```

The Python visualization layer reads the state history generated by the C++ simulator; it does not calculate the vehicle dynamics itself.

## Current Model

The current vehicle is a simplified rocket/VTOL-style rigid body whose longitudinal and thrust axis is body +z. The world frame uses +z upward. The vehicle quaternion maps vectors from the body frame into the world frame.

The aerodynamic model currently uses separate axial and lateral drag forces, a center-of-pressure offset for static restoring moments, and airspeed-dependent rotational damping. The model is intentionally being developed incrementally so that individual physical and numerical components can be validated before additional complexity is introduced.

## Planned Development

Future development will extend the simulator with more realistic flight physics and control capabilities, including altitude-dependent atmospheric properties, time-varying thrust and vehicle mass, improved aerodynamic coefficient models, and guidance, navigation, and control (GNC).
